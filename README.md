# Customer_Behavior
data analytics project showcasing customer behavior using python , sql and Powerbi

Data Analytics Project
Overview

This project demonstrates a complete data analytics workflow using Python, SQL Server, and Power BI. The objective was to analyze the dataset, clean and transform the data, perform exploratory data analysis (EDA), execute SQL queries for insights, and create an interactive dashboard for reporting and decision-making.

The project showcases skills in data cleaning, visualization, SQL querying, dashboard development, and business insight generation.

Dataset

The dataset contains structured data used for analysis and reporting purposes.

Key Features
Customer information
Product details
Sales/transaction records
Purchase behavior
Revenue and performance metrics
Tools & Technologies
Python – Data analysis and preprocessing
Pandas & NumPy – Data manipulation
Matplotlib & Seaborn – Data visualization
SQL Server – Database management and SQL analysis
Power BI – Dashboard creation and reporting
Jupyter Notebook / Google Colab – Development environment
Project Workflow
1. Data Loading
Imported dataset into Python using Pandas
Inspected dataset structure and data types
2. Data Cleaning
Removed duplicate records
Handled missing values
Corrected inconsistent data formats
Renamed columns for better readability
3. Exploratory Data Analysis (EDA)
Analyzed trends and patterns
Created visualizations for better understanding
Identified key business insights
4. SQL Analysis
Imported cleaned data into SQL Server
Wrote SQL queries for:
Aggregations
Joins
Filtering
Ranking
Customer segmentation
Business insights
5. Power BI Dashboard
Built an interactive dashboard
Added charts, KPIs, slicers, and filters
Visualized important metrics and trends
6. Report Generation
Summarized findings and business insights
Documented analysis process and results
Dashboard Highlights

The Power BI dashboard includes:

Sales performance overview
Customer behavior analysis
Revenue trends
Product/category performance
Interactive filters and slicers
